Task #2 - CountUpperLowerNumbers

    Create a file called CountUpperLowerNumbers.js in your Practice_Programming project and inside the day##_tasks package 

        Task:
                Write a function that accepts a String and Counts uppercase letters, lowercase letters, and numbers
            
            
                    Ex:
                        Input:
                            2juMp41EEkd4s4
                        Output:
                            3 uppercase letters
                            6 lowercase letters
                            5 numbers

                    Note: To find the Uppercase, lowercase, and number "Regex" is being used in JavaScript. Ask in Copilot AI to get more info

                            /^\d$/.test(ch)             // digit
                            /^[a-z]$/.test(ch)          // English lowercase letter
                            /^[A-Z]$/.test(ch)          // English uppercase letter


                            Ex:
                                let ch = "G";

                                console.log(/^\d$/.test(ch));    // false
                                console.log(/^[a-z]$/.test(ch)); // false
                                console.log(/^[A-Z]$/.test(ch)); // true
